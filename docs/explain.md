# Weighted factor explanations

`loupe explain -p incident-factors` decomposes a finite whole state by asking the primary question and declared `[[factors]]` together. See [the example preset](../examples/incident-factors.toml). `-f FILE` also accepts a single-primary question document with factors. Explicit input modes and unit/window packing permit per-unit reports; the default is whole input. Each factor has a unique `[a-z][a-z0-9_-]*` ID, a finite positive weight, optional `invert`, instructions and Noul or Score type. Noul is the default. Score needs at least two levels. Fields use `factor:<id>` in declaration order, after the primary and before companion signals. Normal templates, context, schema limits, exact counting, complete-request caching and budgets apply to the whole joint schema.

The formula is `sum(normalized_weight * value)`. Noul value is its returned probability of true. Score value is the probability-weighted mean level, divided by the total probability mass and by `levels - 1`. Computing it from the distribution avoids relying on a separately rounded backend `score`. `invert=true` replaces a value with `1-value`. Weights are normalized in code, scaling by the maximum first to avoid overflow; an unrepresentable weight range is rejected. The composite is a numerical index in [0,1], with no event probability, independence assumption, calibrated confidence or causal claim. All fields can influence one another through the joint head, including the primary answer.

Each factor may declare its own threshold/margin (Noul) or minimum confidence/gap (Score) under `[factors.policy]`. These flag its assessment as uncertain; the report still includes every contribution. CLI decision-policy flags, uncertain-file, keep-going and classification calibration pins are inapplicable and exit 64. Changing factors/weights changes run identity and prevents incompatible journal replay. Factor presets apply to `explain`, `tokens` plans, raw multi-question `ask` and preset lint. Ordinary filters/features, pair rubrics and classification evaluation refuse them rather than silently skip the composite schema.

Plain/annotate prints the composite followed by each factor value, weight, contribution and uncertainty. TSV has three columns: unit index, composite and a JSON factor map. JSONL preserves common unit/answer/model/cached fields, `composite` with formula/score/factors, raw factor answers, normalized weights, assessment, full request/counts/response and original location. Window reports bind each factor to its own source ID and retain the complete joint response. `--why` adds declared signals. Explicit split/combine, focus and truncation use the shared view controls and retain their provenance; the index then describes that explicitly derived view. A composite is not substituted for the raw primary answer. Ask remains the API response object.

`--failed`/`--resume` use the general run journal. Clean completed replay emits nothing and makes no inference requests; arbitrary stdout still has its documented flush/acknowledgement crash gap. No factors means exit 64, malformed definitions exit 64, over-budget input/schema exit 65, and model errors use the shared failure contract. Successful reports exit 0.

`--ensemble` also accepts variants targeting `factor:<id>`; omitted `field` continues to target the sole primary. See [the factor example](../examples/ensemble-factors.toml). All original factors precede appended variants and signals in the encoded schema. Factor values come from the equal mean distribution before complement/weighting. Ensembled contributions retain raw `answer`, add `raw_assessment` and `ensemble`, and report the mean/agreement assessment in `assessment`. Unvaried factors keep their existing shape. JSON includes a primary `ensemble` report when declared; TSV's factor map includes the same contribution metadata. Plain output shows mean values and effective uncertainty. All context, exact limits, window source bindings and agreement-pinned recovery rules apply. Changing `--min-agreement` refuses replay even though it does not change model input tokens. The index remains uncalibrated.

Qualification includes hand-computed mixed Noul/Score/complement arithmetic, extreme weights, invalid shapes, window bindings, real CLI guards and actual server response arithmetic/replay. The [reference API](https://huggingface.co/Cloudflare/clef-flash/blob/main/README.md#jev--systemone-api) supplies per-field distributions; the composite formula is Loupe's declared application policy. Held-out composite usefulness, full live identity/cache and refreshed native/platform release artifacts remain separate gates.
